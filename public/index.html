📖 操作说明

  • 预算设置：点击「设置预算」为每个分类设置月度上限，系统自动预警（≥80% 黄，≥100% 红）
  • 账单日历：切换到日历标签查看未来 60 天扣费，支持按分类筛选，悬停格子查看明细
  • CSV 导出：点击日历上方「导出 CSV」下载未来 60 天扣费清单（含筛选分类）
  • 新增订阅：点击「＋ 新增订阅」按钮，填写会员名称、金额、扣费周期、下次扣费日和分类
  • 自动重算：新增、编辑、停用、续费、删除订阅后，预算占用与未来扣费自动更新
  • 扣费周期：monthly=每月, quarterly=每季, yearly=每年

✅ 功能验证命令（需先启动服务 npm start）

=== 1. 预算超限验证 ===
# 设置分类预算
curl -X PUT http://localhost:3000/api/budgets -H "Content-Type: application/json" -d "{\"category\":\"影音娱乐\",\"budget_limit\":100}"
# 新增一个超过预算的订阅（月均 > 100）
curl -X POST http://localhost:3000/api/subscriptions -H "Content-Type: application/json" -d "{\"name\":\"测试会员\",\"amount\":128,\"cycle\":\"monthly\",\"next_billing_date\":\"2026-07-01\",\"category\":\"影音娱乐\"}"
# 查看预算占用，应该 level=danger，percentage>100
curl http://localhost:3000/api/budgets/usage

=== 2. 日历筛选验证 ===
# 查看全部 60 天扣费
curl "http://localhost:3000/api/calendar?days=60"
# 按分类筛选
curl "http://localhost:3000/api/calendar?days=60&category=影音娱乐"
# 查看返回：total_events / total_amount / events 数组

=== 3. CSV 导出验证 ===
# 全部分类 60 天
curl "http://localhost:3000/api/export/csv?days=60" -o export_all.csv
# 按分类筛选 60 天
curl "http://localhost:3000/api/export/csv?days=60&category=工具软件" -o export_tools.csv
# 打开 CSV 查看字段：订阅名称、金额(元)、扣费日期、分类、状态
